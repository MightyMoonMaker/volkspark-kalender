# Volkspark-Kalender

Abonnierbarer Kalender mit allen Veranstaltungen in der Barclays Arena und im
Volksparkstadion Hamburg. An diesen Tagen ist die Uwe-Seeler-Allee für den
öffentlichen Verkehr gesperrt, was Navigations-Apps oft nicht anzeigen.

## Abonnieren
Kalender-URL: https://<benutzername>.github.io/volkspark-kalender/volkspark.ics

Google Kalender: Andere Kalender > Per URL > Adresse einfügen.

## Quellen
- Terminliste der Barclays Arena
- Heimspiele des HSV
- Baustellen-Datendienst der Stadt Hamburg

Die Termine werden täglich automatisch aktualisiert. Angaben ohne Gewähr.
